Pizza Hut
Pizzazz App

University project prototype based on the proposed redesign and ethnography tasks. A warmer visual refresh with realistic food imagery, a welcoming entry screen and interactive ordering.

  • One-tap demo login
  • Browse & search food
  • Visual pizza builder
  • Custom toppings & live pricing
  • Cart & simulated checkout
  • Order tracking demo
  • Loyalty points & mini-game

Try this: Log In → Pizza → Margherita → + Add → Choose size → Add to cart → Checkout → Track order.

This is a local prototype. Payments, food delivery, notifications and third-party integrations are simulated.

DEMO WALKTHROUGH

Test the redesign

This interactive prototype demonstrates three ethnography usability tasks.

Task 1: Find and order food through a clear menu.

Task 2: Build a pizza, see toppings visually, and review the live price.

Task 3: Follow preparation and delivery stages.

Use Advance status on the tracking screen to simulate progress, or let the demo auto-advance.

No account, payment, API key, internet connection or installation required.
